# Claude Commands

A collection of user-defined slash commands for [Claude Code](https://claude.ai/download).

## Installation

Copy any `.md` file to your `~/.claude/commands/` directory. The command becomes available as `/{filename}`.

## Available commands

| Command | Description |
|---------|-------------|
| [ssp](./ssp.md) | Take a phone screenshot and save to project assets |
